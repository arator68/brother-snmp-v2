Home Assistant Integration for Brother scanners via SNMP.

## Features

- Page counter
- Model
- Serial number
- Firmware
- Roller counter

## Installation

### HACS

1. Add custom repository
2. Install integration
3. Restart Home Assistant

### Manual

Copy folder to:

custom_components/brother_snmp_v2
